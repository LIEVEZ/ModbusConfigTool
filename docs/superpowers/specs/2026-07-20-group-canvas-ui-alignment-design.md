# 分组自由画布界面完整对齐设计

- 日期：2026-07-20
- 状态：已批准
- 原型基线：[docs/ui/group-drag-prototype.html](../../ui/group-drag-prototype.html)
- 既有架构设计：[2026-07-17-group-canvas-multi-connection-design.md](./2026-07-17-group-canvas-multi-connection-design.md)

## 1. 目标

将当前 Qt 5 主界面完整对齐“连接端口 + 分组自由画布”原型。保留现有多端口、分组、寄存器、运行时和持久化结构，集中修正主窗口、连接端口栏、分组画布、分组卡片及相关 QSS，不恢复旧版固定表格仪表盘。

## 2. 实现策略

采用原型驱动的局部重构：复用现有 ViewModel、应用服务、领域模型和对话框，重构视图组合方式并补齐必要信号。避免在当前纯绘制卡片上继续叠加鼠标交互补丁，也不整体重写无关视图层。

## 3. 主窗口结构

1. 菜单栏下增加原型工具栏，提供“＋ 新增分组”按钮和分组数量显示。
2. 主体使用三栏布局：左侧连接端口栏默认约 250 px，中间分组画布自适应，右侧事件日志栏默认约 300 px。
3. 三栏允许用户调整宽度，但应设置合理的最小宽度，避免控件被压缩到不可用。
4. 中间画布放入滚动区域，保留网格背景；分组卡片坐标超出可视区域时仍可访问。
5. 默认窗口大小为 1600×900，保持当前最小窗口尺寸可用。
6. 状态栏继续保留，运行状态和提示变化不得引发布局跳动。

## 4. 连接端口栏

每张端口卡片显示：

- 状态灯：运行中为绿色，空闲为灰色，故障为红色，启动或停止过程使用警告色。
- 端口名称和 TCP/RTU 类型。
- TCP 地址或 RTU 串口参数。
- 轮询周期、从站地址和实际绑定分组数。
- 连接/断开、编辑和删除按钮。

行为要求：

1. 连接按钮根据端口实际运行状态切换为“连接”或“断开”。
2. 连接调用 `startPort()`，断开调用 `stopPort()`；Starting 和 Stopping 状态禁止重复操作。
3. Fault 状态显示红色状态灯，并允许用户重新连接。
4. 新增和编辑继续复用 `ConnectionConfigDialog`。
5. 删除已绑定端口时提示受影响的分组数量；确认后由既有业务逻辑解除绑定。
6. 分组绑定变化后，端口卡片上的绑定数量立即刷新。
7. 没有端口时显示原型对应的空状态提示。

## 5. 分组画布与卡片

### 5.1 画布

- 使用暖灰色网格背景。
- 无分组时显示居中的新增引导。
- 点击空白区域清除当前选择。
- 画布内容尺寸根据卡片位置扩展，并通过滚动区域访问超出可视区域的卡片。

### 5.2 卡片结构

分组卡片采用组合控件实现，显示：

- 分组颜色顶部色条。
- 分组名称。
- 启用或停用药丸。
- 描述文本。
- 寄存器数量。
- 通信端口下拉框，包含“未绑定端口”。

停用分组使用灰色药丸并整体灰显，但仍保留拖动、编辑和重新启用能力。

### 5.3 卡片交互

1. 点击启用药丸调用分组启停接口；失败时恢复原状态并记录日志。
2. 修改端口下拉框调用分组绑定接口；失败时恢复原选项并记录日志。
3. 药丸和下拉框独立处理鼠标事件，不触发卡片拖动。
4. 卡片超过拖动阈值后才进入拖动状态；释放鼠标时保存一次坐标。
5. 悬停卡片显示跟随鼠标的摘要，内容为分组名称、描述、寄存器数量和前三条实时值。
6. 双击卡片打开该组完整实时值窗口。
7. 右键菜单顺序为：寄存器配置、查看实时数值、分隔线、导入 CSV、导出 CSV、分隔线、编辑分组、删除分组。
8. 删除默认分组继续交由既有领域保护逻辑拒绝，不在界面层绕过。

## 6. 状态与数据流

1. `MainWindow` 负责组合视图、转发用户意图并显示操作结果。
2. `ConnectionPortListView` 接收端口列表、分组列表和端口运行状态，只负责渲染及发出新增、编辑、删除、启动、停止请求。
3. `GroupCanvasView` 接收完整工程文档，管理卡片位置、画布内容范围和选中状态。
4. `GroupCardWidget` 发出启用切换、端口绑定、拖动完成、双击和右键请求，不直接修改领域对象。
5. `MainWindowViewModel` 执行现有服务操作；成功后刷新文档，失败时返回 `OperationResult`。
6. 端口状态以 ViewModel 的运行时信号为唯一来源，界面不得通过按钮文字猜测运行状态。
7. 文档刷新后恢复当前选中的分组；正在拖动或操作下拉框时避免无意义的全量重建。

## 7. 视觉规范

- 页面背景：`#f2f1ed`。
- 面板和控件背景：`#f7f7f4`。
- 卡片背景：白色或原型对应的浅色。
- 主文本：`#26251e`。
- 主操作色：`#f54e00`。
- 成功色：`#1f8a65`。
- 警告色：`#c08532`。
- 错误色：`#cf2d56`。
- 卡片圆角、边框、按钮高度、内外边距、标题层级和状态药丸对齐原型。

主要样式通过明确的 `objectName` 收口到 QSS。仅保留确实依赖运行状态或分组颜色的动态样式，避免在 C++ 中重复维护大段静态 QSS。

## 8. 错误处理

1. 启用切换、端口绑定和坐标保存失败时显示可读提示，并将失败记录到事件日志。
2. 端口启动、停止和故障由运行时状态信号驱动状态灯与按钮，不提前假定操作成功。
3. 删除已绑定端口前显示明确影响范围。
4. 空端口、未绑定端口、空分组和无实时数据均提供稳定的空状态，不显示无意义的空白区域。

## 9. 影响范围

预计修改：

- `Source/Views/Main/main_window.{h,cpp}`：工具栏、三栏组合、状态转发和视图刷新。
- `Source/Views/Connection/connection_port_list_view.{h,cpp}`：端口卡片、绑定数量和运行状态。
- `Source/Views/Groups/group_canvas_view.{h,cpp}`：滚动画布、内容范围和交互转发。
- `Source/Views/Groups/group_card_widget.{h,cpp}`：组合控件、药丸、端口下拉、灰显和悬停摘要。
- `Source/ViewModels/Main/main_window_view_model.{h,cpp}`：仅补齐界面所需但当前缺失的查询或操作入口。
- `Source/Resources/Styles/*.qss` 和 `Resources.qrc`：统一静态视觉样式。
- 相应 Qt Test 文件：主窗口、端口栏和分组卡片的关键状态检查。

不修改策略引擎、数值转换、CSV 字段格式和 Modbus worker 协议行为。

## 10. 验证与验收

### 自动检查

- 主窗口存在工具栏、三栏视图和状态栏。
- 工具栏显示新增分组入口和正确分组数量。
- 端口卡片显示正确绑定数及连接状态。
- 分组卡片包含启用药丸和通信端口下拉框。
- 启用切换、端口绑定、拖动完成信号参数正确。
- 停用状态和端口运行状态对应正确的控件状态。

### 人工回归

逐项对照 `group-drag-prototype.html` 检查：

- 三栏尺寸和视觉层级。
- 工具栏、端口卡片和分组卡片样式。
- 卡片拖动、悬停、双击、右键、启用药丸和端口下拉。
- 端口连接/断开、编辑、删除和绑定数量同步。
- 空状态、停用灰显、错误状态和窗口缩放。

### 构建验证

所有代码修改完成后统一执行 Qt 5.14.2 qmake 构建验证，不在修改过程中反复编译。构建失败必须修复后再宣告完成。

## 11. 完成条件

1. 主界面结构、视觉和交互完整对齐自由画布原型。
2. 原型列出的端口与分组卡片交互全部可用。
3. 不破坏当前业务服务、持久化和运行时功能。
4. 自动检查通过，qmake 构建通过，人工原型对照无阻断差异。
